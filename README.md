# 🗡️ Desafio: Classificador de Nível de Herói

Projeto desenvolvido como parte do desafio prático da **DIO (Digital Innovation One)** para exercitar conceitos fundamentais de lógica de programação.

## 📌 Objetivo

O objetivo principal é criar um programa que leia o **nome** e a **quantidade de experiência (XP)** de um herói e determine o seu nível com base nos seguintes critérios:

| XP | Nível |
| :--- | :--- |
| Menor que 1.000 | **Ferro** |
| Entre 1.001 e 2.000 | **Bronze** |
| Entre 2.001 e 5.000 | **Prata** |
| Entre 5.001 e 7.000 | **Ouro** |
| Entre 7.001 e 8.000 | **Platina** |
| Entre 8.001 e 9.000 | **Ascendente** |
| Entre 9.001 e 10.000 | **Imortal** |
| Maior ou igual a 10.001 | **Radiante** |

## 🚀 Tecnologias Utilizadas

- **Java** (JDK 11 ou superior)
- **Git & GitHub**

## 🧠 Conceitos Aplicados

- **Variáveis**: Armazenamento de dados do herói (nome e XP).
- **Estruturas de Decisão** (`if / else if / else`): Classificação do nível com base no XP.
- **Entrada e Saída de Dados**: Leitura dos dados via console com `Scanner` e exibição da mensagem final.
